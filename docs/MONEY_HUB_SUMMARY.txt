================================================================================
KEY DESIGN DECISIONS
================================================================================

1. SCOPED CSS — All tokens/classes prefixed --m- / .m-, wrapped in .money-hub
2. LIGHT THEME — Apple blue, white surfaces, generous whitespace, calm aesthetic
3. NO CURSOR-POINTER ON CARDS — Only interactive buttons get it (Aaron's preference)
4. COLOR-BLIND SAFE — Always pair color with icon or label
5. GLOSSARY INTEGRATION — <Term> component with hover-fetched definitions
6. SECTION AUTONOMY — No props required, each fetches own data
7. TABULAR NUMERALS — All numbers use monospace + tabular-nums for alignment
8. LAZY-LOADED SECTIONS — Code-split for performance
